# 🦌 OTTO-JÄGER — Groupe 08

Ce dépôt contient l'intégralité des fichiers sources, des codes de programmation et de la documentation du projet **OTTO-JÄGER**, développé par le **Groupe 08** dans le cadre de la première année à **UniLaSalle Amiens**.

Notre robot est une version lourdement modifiée et personnalisée du robot humanoïde open-source Otto, arborant un design et un univers graphique directement inspirés de la célèbre marque **Jägermeister**. Il est conçu pour s'adapter à toutes les épreuves techniques des **Ottolympiades** (Chrono challenge, Course d'obstacle, Otto Sumo, Tir à la corde).

---

## 🚀 Contenu du Repository

Le projet est structuré de la manière suivante :

*   📂 `/docs` : Contient l'ensemble des fichiers de notre site de documentation technique (géré via le thème *Just-the-Docs*).
*   📂 `/src` *(ou votre dossier de code)* : Regroupe les codes sources Arduino / ESP32 pour la gestion des servomoteurs, du capteur ultrason et de la configuration de la télécommande sans fil.
*   📂 `/3D_Models` *(optionnel)* : Contient les exports ou liens vers nos composants CAO modifiés.

## 🛠️ Spécifications de l'OTTO-JÄGER

> **Architecture de base :** 
> * Microcontrôleur **ESP32** (Carte sur mesure MakerSpace).
> * 4 servomoteurs pour la cinématique de marche.
> * Capteur de distance ultrason HC-SR04.
> * Batterie 9V rechargeable par USB-C.
> * Double mode opérationnel : Autonome & Télécommandé via l'application **RemoteXY**.
