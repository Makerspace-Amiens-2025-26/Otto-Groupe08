# 1. Modélisation & Impression 3D

Cette étape présente la préparation des pièces du robot au MakerSpace.

## 🛠️ OnShape (CAO)
Nous avons modifié le modèle de base sur OnShape pour :
* Faire de la place pour la carte ESP32 et la batterie.
* Ajouter des emplacements pour les **6 moteurs** (4 pour les jambes + 2 pour les bras).

## 🖨️ Impression 3D
Le robot utilise un code couleur simple : **Noir et Blanc**.
* **Tête et Corps :** Plastique Noir.
* **Jambes, Pieds et Bras :** Plastique Blanc.

### Réglages de l'imprimante :
* **Remplissage :** 20% (en Gyroïde) pour que le corps soit solide pendant les chocs.
* **Épaisseur :** 3 parois pour pouvoir visser les moteurs solidement.
